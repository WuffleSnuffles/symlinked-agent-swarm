## 1. Executive Summary & Component Boundary

In the Symlinked Agent Swarm System, the **Overseer** is not merely a conversational dispatcher; it acts as an autonomous meta-programmer. When the swarm encounters recurring engineering challenges, repetitive workflows, or specialized domain needs (e.g., resolving complex git merge conflicts, querying SQLite databases, running custom linters, or bridging to external APIs), the Overseer synthesizes **modular, reusable agent capabilities** in two primary formats:

1. **Agentic Skills**: Reusable procedural knowledge bases and workflows structured as `.agents/skills/<name>/SKILL.md` (with optional `scripts/` and `references/`), adhering strictly to the Agentic Skill specification with YAML frontmatter.
2. **Model Context Protocol (MCP) Servers**: Executable JSON-RPC stdio servers (`index.mjs` or `server.py`) with formal JSON Schema tool definitions registered in `.agents/mcp/mcp_config.json`.
3. **Learned Memory, Skills & MCP Vault Backend**: An aggregation engine consolidating learned preferences (`.swarm/memory/preferences.json`), active skills (`.agents/skills/`), and registered MCP servers (`.agents/mcp/mcp_config.json`) into a unified catalog for the Panopticon UI Vault tab, coupled with an interactive dry-run playground test engine (`POST /api/mcp/test-tool` and `POST /api/skills/test-script`).

### The Zero-Copy Worktree Invariant
Crucially, because all 16 cubicle worktrees (`worktrees/cubicle-01..16`) link `<worktree>/.agents` directly to `<root>/.agents` via zero-privilege NTFS Directory Junctions (`IO_REPARSE_TAG_MOUNT_POINT`), **any Skill or MCP server generated by the Overseer in `<root>/.agents` is instantaneously and zero-copy accessible inside every cubicle worktree without Git commits, file copying, or server restarts**.

## 2. Autonomous Skill Generator Architecture

### 2.1 File & Directory Layout
Every synthesized skill is stored in its own directory under `.agents/skills/<name>/`:

```
.agents/skills/<skill-name>/
├── SKILL.md                 # Primary contract & instructions (REQUIRED)
├── scripts/                 # Executable helper scripts (OPTIONAL)
│   ├── run.ps1
│   ├── resolve.sh
│   └── helper.mjs
├── references/              # Contextual markdown or documentation (OPTIONAL)
│   └── guide.md
└── resources/               # Configuration templates or data assets (OPTIONAL)
    └── config.template.json
```

### 2.2 Strict Agentic Skill Specification
A valid `SKILL.md` MUST strictly begin with a YAML frontmatter block bounded by `---` on lines 1 and ending with `---`, followed by a markdown body containing mandatory architectural sections.

#### Schema Template:
```markdown
---
name: git-rebase-sync
description: Rebase active cubicle branch onto latest main cleanly with AST conflict resolution
---

# Git Rebase Sync Skill

## Critical Rules
- Never force push or drop incoming changes without semantic diff validation.
- Always run the test suite against resolved code before committing.
- Maintain atomic commit history on cubicle worktree branches.

## When to Use
- Triggered whenever a cubicle branch encounters a merge or rebase conflict during review or task consolidation.
- Triggered when user prompts for branch synchronization.

## Step-by-Step Instructions
1. Inspect conflicting files using `git status` and `git diff --check`.
2. Run `scripts/resolve_conflict.ps1 -Branch <branch_name>`.
3. Run verification test suite (`npm test`).
4. Stage resolved files and produce an atomic commit.
```

### 2.3 Security, Sanitization & Validation Invariants

1. **Path Traversal & Name Sanitization**:
   - Skill names must be sanitized to prevent directory traversal attacks.
   - Any name containing `..`, `/`, `\`, null bytes, or characters outside `[a-z0-9_-]` is immediately rejected with:
     `Error: SECURITY_VIOLATION: Skill name contains illegal path traversal characters.`
   - Normalized name: `name.toLowerCase().trim().replace(/[^a-z0-9_-]/g, '')`.
2. **YAML Frontmatter Parsing**:
   - Regex validation: `^---\r?\n([\s\S]*?)\r?\n---`
   - If missing opening or closing delimiter:
     `{ valid: false, error: 'MALFORMED_FRONTMATTER: Missing closing ---' }`
   - Key extraction: Must extract `name` and `description`.
   - Invariant: `name` in frontmatter must match the directory name (or sanitized name).
   - Invariant: `description` must be a non-empty string.
3. **Mandatory Markdown Sections**:
   - The body is validated to confirm the presence of:
     - `## Critical Rules`
     - `## When to Use`
     - `## Step-by-Step Instructions`
4. **Script Execution Validation**:
   - If `scripts/` contains scripts, their file extensions must belong to an allowlist: `.ps1`, `.sh`, `.js`, `.mjs`, `.py`, `.bat`, `.cmd`.
   - Scripts are checked for execution syntax (e.g. `node --check` for JS/MJS, syntax checks for Python/PowerShell).

## 3. Autonomous MCP Server Generator Architecture

### 3.1 Model Context Protocol (MCP) Standard Compliance
The Model Context Protocol establishes open JSON-RPC 2.0 communication over standard I/O (`stdio`). The synthesized MCP servers operate as standalone child processes communicating with the swarm engine or cubicle agents.

### 3.2 Directory & Configuration Layout
Synthesized MCP servers reside under `.agents/mcp/<server-name>/`:

```
.agents/mcp/
├── mcp_config.json              # Authority registry of all MCP servers
└── <server-name>/
    ├── index.mjs                # Server execution script (Node.js ESM)
    ├── package.json             # Minimal manifest (type: module)
    └── tools/                   # Tool schema definitions
        ├── query_schema.json
        └── run_query.json
```

### 3.3 The Registry Authority (`.agents/mcp/mcp_config.json`)
The canonical registry file tracks commands, arguments, environment variables, and tool eager/lazy flags:

```json
{
  "mcpServers": {
    "sqlite-inspector": {
      "command": "node",
      "args": [".agents/mcp/sqlite-inspector/index.mjs"],
      "env": {
        "DB_PATH": "./.swarm/state.db"
      },
      "tools": {
        "inspect_table": {
          "eager": true
        },
        "run_query": {
          "eager": false
        }
      }
    }
  }
}
```

#### Fault Tolerance & Recovery Invariants for `mcp_config.json`:
- **Missing File**: Initializes automatically as `{ "mcpServers": {} }`.
- **Corrupted / Invalid JSON**: Caught via try-catch, backed up to `mcp_config.json.bak`, falls back to `{ "mcpServers": {} }`, and logs an incident without crashing the server.
- **Duplicate Registration**: Safely merges/updates the server entry while preserving all other server registrations.

### 3.4 Tool Schema Specification (`tools/<tool_name>.json`)
Each tool schema is stored as an individual JSON Schema definition under `tools/`:

```json
{
  "name": "inspect_table",
  "description": "Returns schema columns, types, and primary keys for a SQLite table",
  "parameters": {
    "type": "object",
    "properties": {
      "table_name": {
        "type": "string",
        "description": "Name of the table to inspect"
      }
    },
    "required": ["table_name"],
    "additionalProperties": false
  }
}
```

- **Defaulting Invariant**: If `parameters` is omitted in the generation payload, it defaults to `{ type: 'object', properties: {} }`.

### 3.5 Native Node.js ESM JSON-RPC Stdio Server Template
To guarantee single-binary bundling and zero runtime installation hurdles, the synthesized `index.mjs` uses native Node.js ESM without requiring external npm dependencies:

```javascript
/**
 * Auto-generated Model Context Protocol (MCP) Server
 * Transport: stdio (newline-delimited JSON-RPC 2.0)
 */
import readline from 'node:readline';
import fs from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const toolsDir = path.join(__dirname, 'tools');

// Load tool schemas from tools/*.json
async function loadTools() {
  const tools = [];
  try {
    const files = await fs.readdir(toolsDir);
    for (const f of files) {
      if (f.endsWith('.json')) {
        const raw = await fs.readFile(path.join(toolsDir, f), 'utf8');
        tools.push(JSON.parse(raw));
      }
    }
  } catch {}
  return tools;
}

// Tool implementation registry
const toolHandlers = {
  // Handlers populated by Overseer generator
};

const rl = readline.createInterface({ input: process.stdin, output: process.stdout, terminal: false });

function sendResponse(id, result, error = null) {
  const msg = { jsonrpc: '2.0', id };
  if (error) {
    msg.error = error;
  } else {
    msg.result = result;
  }
  process.stdout.write(JSON.stringify(msg) + '\n');
}

rl.on('line', async (line) => {
  const text = line.trim();
  if (!text) return;

  let req;
  try {
    req = JSON.parse(text);
  } catch {
    sendResponse(null, null, { code: -32700, message: 'Parse error' });
    return;
  }

  const { id, method, params } = req;

  if (method === 'initialize') {
    sendResponse(id, {
      protocolVersion: '2024-11-05',
      capabilities: { tools: {} },
      serverInfo: { name: '{{SERVER_NAME}}', version: '1.0.0' }
    });
  } else if (method === 'notifications/initialized') {
    // Client acknowledged initialization
  } else if (method === 'tools/list') {
    const tools = await loadTools();
    sendResponse(id, {
      tools: tools.map(t => ({
        name: t.name,
        description: t.description,
        inputSchema: t.parameters || { type: 'object', properties: {} }
      }))
    });
  } else if (method === 'tools/call') {
    const { name, arguments: args } = params || {};
    const handler = toolHandlers[name];
    if (!handler) {
      sendResponse(id, null, { code: -32601, message: `Tool '${name}' not found` });
      return;
    }
    try {
      const output = await handler(args || {});
      sendResponse(id, {
        content: [{ type: 'text', text: typeof output === 'string' ? output : JSON.stringify(output) }],
        isError: false
      });
    } catch (err) {
      sendResponse(id, {
        content: [{ type: 'text', text: err.message }],
        isError: true
      });
    }
  } else {
    if (id !== undefined) {
      sendResponse(id, null, { code: -32601, message: `Method '${method}' not found` });
    }
  }
});
```

### 4.2 Interactive Test Execution & Playground Engine

The Vault backend provides dedicated test execution endpoints allowing operators and the Overseer to perform live dry runs of synthesized MCP tools and skill scripts before unleashing them on production worktrees.

#### 1. MCP Tool Test Runner (`POST /api/mcp/test-tool`):
- **Request Payload**:
  ```json
  {
    "serverName": "sqlite-inspector",
    "toolName": "inspect_table",
    "arguments": { "table_name": "tasks" },
    "timeoutMs": 5000
  }
  ```
- **Execution Protocol**:
  1. Retrieve registered command and arguments from `mcp_config.json`.
  2. Spawn subprocess with piped `stdin` and `stdout`.
  3. Send `initialize` request:
     `{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"panopticon-vault-tester","version":"1.0.0"}}}`
  4. Await response within timeout window (default 5000ms).
  5. Send notification `notifications/initialized`.
  6. Send `tools/call` request:
     `{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"inspect_table","arguments":{"table_name":"tasks"}}}`
  7. Capture result, measure elapsed duration (`executionTimeMs`), capture any `stderr` logs, and cleanly terminate process.
- **Response Payload**:
  ```json
  {
    "success": true,
    "result": {
      "content": [{ "type": "text", "text": "{\"columns\":[\"id\",\"title\",\"status\"]}" }],
      "isError": false
    },
    "executionTimeMs": 38,
    "logs": ""
  }
  ```

#### 2. Skill Script Test Runner (`POST /api/skills/test-script`):
- **Request Payload**:
  ```json
  {
    "skillName": "git-rebase-sync",
    "scriptName": "resolve_conflict.ps1",
    "arguments": ["-DryRun"],
    "timeoutMs": 5000
  }
  ```
- **Execution Protocol**:
  1. Verify script path resides strictly within `.agents/skills/<skillName>/scripts/`.
  2. Execute using appropriate shell based on file extension (`.ps1` -> `powershell`, `.mjs`/`.js` -> `node`, `.py` -> `python`, `.sh` -> `bash`).
  3. Enforce execution timeout.
  4. Return `stdout`, `stderr`, `exitCode`, and `executionTimeMs`.

```typescript
/**
 * src/server/mcp-generator.ts
 *
 * Production Skill & MCP Server Generator and Unified Vault Backend.
 * Implements Feature 6: Autonomous Skill Generator, MCP Server Generator,
 * Stdio JSON-RPC Tool Invocation, and Vault Catalog Aggregation.
 */

import fs from 'node:fs/promises';
import path from 'node:path';
import { spawn } from 'node:child_process';
import EventEmitter from 'node:events';

export interface SkillGeneratePayload {
  name: string;
  description: string;
  criticalRules?: string[];
  whenToUse?: string[];
  stepByStepInstructions?: string[];
  markdownBody?: string;
  scripts?: Array<{ name: string; content: string }>;
  references?: Array<{ name: string; content: string }>;
}

export interface SkillSummary {
  name: string;
  description: string;
  path: string;
  status: 'ready' | 'invalid';
  scripts: string[];
  references: string[];
  content?: string;
  error?: string;
}

export interface McpToolDefinition {
  name: string;
  description: string;
  parameters?: any;
  eager?: boolean;
  handlerCode?: string;
}

export interface McpGeneratePayload {
  name: string;
  command?: string;
  args?: string[];
  env?: Record<string, string>;
  tools: McpToolDefinition[];
  serverCode?: string;
}

export interface McpServerConfigEntry {
  command: string;
  args: string[];
  env?: Record<string, string>;
  tools?: Record<string, { eager: boolean }>;
}

export interface McpConfigDatabase {
  mcpServers: Record<string, McpServerConfigEntry>;
}

export interface McpServerSummary {
  name: string;
  status: 'ready' | 'error';
  command: string;
  args: string[];
  env: Record<string, string>;
  tools: Array<{
    name: string;
    description: string;
    eager: boolean;
    parameters: any;
  }>;
}

export interface VaultCatalog {
  total_preferences: number;
  total_skills: number;
  total_mcp_servers: number;
  preferences: any[];
  skills: SkillSummary[];
  mcp_servers: McpServerSummary[];
}

export class SkillMcpManager extends EventEmitter {
  private repoRoot: string;
  private agentsDir: string;
  private swarmDir: string;
  private skillsDir: string;
  private mcpDir: string;
  private mcpConfigFile: string;

  constructor(repoRoot: string) {
    super();
    this.repoRoot = path.resolve(repoRoot);
    this.agentsDir = path.join(this.repoRoot, '.agents');
    this.swarmDir = path.join(this.repoRoot, '.swarm');
    this.skillsDir = path.join(this.agentsDir, 'skills');
    this.mcpDir = path.join(this.agentsDir, 'mcp');
    this.mcpConfigFile = path.join(this.mcpDir, 'mcp_config.json');
  }

  public async initialize(): Promise<void> {
    await fs.mkdir(this.skillsDir, { recursive: true });
    await fs.mkdir(this.mcpDir, { recursive: true });
    await this.ensureMcpConfig();
  }

  // =========================================================================
  // Skill Management
  // =========================================================================

  public sanitizeSkillName(name: string): string {
    if (!name || name.includes('..') || name.includes('/') || name.includes('\\')) {
      throw new Error('SECURITY_VIOLATION: Skill name contains illegal path traversal characters.');
    }
    const sanitized = name.toLowerCase().trim().replace(/[^a-z0-9_-]/g, '');
    if (!sanitized) {
      throw new Error('Skill name must contain at least one valid alphanumeric character.');
    }
    return sanitized;
  }

  public parseFrontmatter(content: string): { valid: boolean; frontmatter?: { name: string; description: string }; error?: string } {
    const match = content.match(/^---\r?\n([\s\S]*?)\r?\n---/);
    if (!match) {
      return { valid: false, error: 'MALFORMED_FRONTMATTER: Missing closing ---' };
    }
    const rawFm = match[1];
    let name = '';
    let description = '';

    const lines = rawFm.split('\n');
    for (const rawLine of lines) {
      const line = rawLine.trim();
      if (line.startsWith('name:')) {
        name = line.substring(5).trim().replace(/^['"]|['"]$/g, '');
      } else if (line.startsWith('description:')) {
        description = line.substring(12).trim().replace(/^['"]|['"]$/g, '');
      }
    }

    if (!name || !description) {
      return { valid: false, error: 'MALFORMED_FRONTMATTER: Missing required name or description field' };
    }

    return { valid: true, frontmatter: { name, description } };
  }

  public async generateSkill(payload: SkillGeneratePayload): Promise<SkillSummary> {
    const skillName = this.sanitizeSkillName(payload.name);
    const targetDir = path.join(this.skillsDir, skillName);
    await fs.mkdir(targetDir, { recursive: true });

    let bodyContent = payload.markdownBody;
    if (!bodyContent) {
      const rules = payload.criticalRules && payload.criticalRules.length > 0
        ? payload.criticalRules.map((r) => `- ${r}`).join('\n')
        : '- Maintain code quality and pass all verification tests.';
      const triggers = payload.whenToUse && payload.whenToUse.length > 0
        ? payload.whenToUse.map((t) => `- ${t}`).join('\n')
        : '- Triggered when relevant task pattern is assigned.';
      const steps = payload.stepByStepInstructions && payload.stepByStepInstructions.length > 0
        ? payload.stepByStepInstructions.map((s, idx) => `${idx + 1}. ${s}`).join('\n')
        : '1. Inspect requirements.\n2. Execute workflow.\n3. Verify test suite.';

      bodyContent = `
# ${skillName.replace(/-/g, ' ').replace(/\b\w/g, (c) => c.toUpperCase())} Skill

## Critical Rules
${rules}

## When to Use
${triggers}

## Step-by-Step Instructions
${steps}
`;
    }

    const skillMdContent = `---
name: ${skillName}
description: ${payload.description || 'Custom autonomous agent skill'}
---
${bodyContent.trim()}
`;

    const skillMdPath = path.join(targetDir, 'SKILL.md');
    await fs.writeFile(skillMdPath, skillMdContent, 'utf8');

    // Write optional scripts
    const scriptFiles: string[] = [];
    if (payload.scripts && payload.scripts.length > 0) {
      const scriptsDir = path.join(targetDir, 'scripts');
      await fs.mkdir(scriptsDir, { recursive: true });
      for (const s of payload.scripts) {
        const safeScriptName = path.basename(s.name);
        await fs.writeFile(path.join(scriptsDir, safeScriptName), s.content, 'utf8');
        scriptFiles.push(safeScriptName);
      }
    }

    // Write optional references
    const referenceFiles: string[] = [];
    if (payload.references && payload.references.length > 0) {
      const refDir = path.join(targetDir, 'references');
      await fs.mkdir(refDir, { recursive: true });
      for (const r of payload.references) {
        const safeRefName = path.basename(r.name);
        await fs.writeFile(path.join(refDir, safeRefName), r.content, 'utf8');
        referenceFiles.push(safeRefName);
      }
    }

    const summary: SkillSummary = {
      name: skillName,
      description: payload.description,
      path: `.agents/skills/${skillName}/SKILL.md`,
      status: 'ready',
      scripts: scriptFiles,
      references: referenceFiles,
      content: skillMdContent,
    };

    this.emit('SKILL_GENERATED', summary);
    return summary;
  }

  public async listSkills(): Promise<SkillSummary[]> {
    const list: SkillSummary[] = [];
    try {
      const entries = await fs.readdir(this.skillsDir, { withFileTypes: true });
      for (const entry of entries) {
        if (!entry.isDirectory()) continue;
        const skillName = entry.name;
        const skillPath = path.join(this.skillsDir, skillName, 'SKILL.md');
        try {
          const content = await fs.readFile(skillPath, 'utf8');
          const parsed = this.parseFrontmatter(content);
          
          let scripts: string[] = [];
          try {
            scripts = await fs.readdir(path.join(this.skillsDir, skillName, 'scripts'));
          } catch {}

          let references: string[] = [];
          try {
            references = await fs.readdir(path.join(this.skillsDir, skillName, 'references'));
          } catch {}

          list.push({
            name: skillName,
            description: parsed.frontmatter?.description || '',
            path: `.agents/skills/${skillName}/SKILL.md`,
            status: parsed.valid ? 'ready' : 'invalid',
            scripts,
            references,
            content,
            error: parsed.error,
          });
        } catch {
          // SKILL.md missing or unreadable
        }
      }
    } catch {}
    return list;
  }

  public async generateMcpServer(payload: McpGeneratePayload): Promise<McpServerSummary> {
    const serverName = this.sanitizeSkillName(payload.name);
    const serverDir = path.join(this.mcpDir, serverName);
    const toolsDir = path.join(serverDir, 'tools');

    await fs.mkdir(toolsDir, { recursive: true });

    // Normalize and persist tool schemas
    const toolSummaries: Array<{ name: string; description: string; eager: boolean; parameters: any }> = [];
    const toolsRecord: Record<string, { eager: boolean }> = {};

    for (const tool of payload.tools) {
      const toolName = this.sanitizeSkillName(tool.name);
      const normalizedParams = tool.parameters && typeof tool.parameters === 'object'
        ? tool.parameters
        : { type: 'object', properties: {} };

      const schema = {
        name: toolName,
        description: tool.description || '',
        parameters: normalizedParams,
      };

      await fs.writeFile(path.join(toolsDir, `${toolName}.json`), JSON.stringify(schema, null, 2), 'utf8');

      const isEager = tool.eager ?? true;
      toolsRecord[toolName] = { eager: isEager };
      toolSummaries.push({
        name: toolName,
        description: tool.description || '',
        eager: isEager,
        parameters: normalizedParams,
      });
    }

    // Generate or write server executable
    const serverScriptPath = path.join(serverDir, 'index.mjs');
    if (payload.serverCode) {
      await fs.writeFile(serverScriptPath, payload.serverCode, 'utf8');
    } else {
      const boilerplate = this.generateMcpServerBoilerplate(serverName, payload.tools);
      await fs.writeFile(serverScriptPath, boilerplate, 'utf8');
    }

    // Update mcp_config.json
    const config = await this.loadMcpConfig();
    const command = payload.command || 'node';
    const relativeScript = `.agents/mcp/${serverName}/index.mjs`;
    const args = payload.args || [relativeScript];

    config.mcpServers[serverName] = {
      command,
      args,
      env: payload.env || {},
      tools: toolsRecord,
    };

    await this.saveMcpConfig(config);

    const summary: McpServerSummary = {
      name: serverName,
      status: 'ready',
      command,
      args,
      env: payload.env || {},
      tools: toolSummaries,
    };

    this.emit('MCP_REGISTERED', summary);
    return summary;
  }

  public async listMcpServers(): Promise<McpServerSummary[]> {
    const config = await this.loadMcpConfig();
    const list: McpServerSummary[] = [];

    for (const [name, entry] of Object.entries(config.mcpServers)) {
      const serverDir = path.join(this.mcpDir, name);
      const toolsDir = path.join(serverDir, 'tools');
      const toolSummaries: Array<{ name: string; description: string; eager: boolean; parameters: any }> = [];

      try {
        const toolFiles = await fs.readdir(toolsDir);
        for (const file of toolFiles) {
          if (!file.endsWith('.json')) continue;
          try {
            const raw = await fs.readFile(path.join(toolsDir, file), 'utf8');
            const parsed = JSON.parse(raw);
            const toolName = parsed.name || path.basename(file, '.json');
            const isEager = entry.tools?.[toolName]?.eager ?? true;
            toolSummaries.push({
              name: toolName,
              description: parsed.description || '',
              eager: isEager,
              parameters: parsed.parameters || { type: 'object', properties: {} },
            });
          } catch {}
        }
      } catch {}

      list.push({
        name,
        status: 'ready',
        command: entry.command,
        args: entry.args,
        env: entry.env || {},
        tools: toolSummaries,
      });
    }

    return list;
  }

  public async getMcpServer(name: string): Promise<McpServerSummary | null> {
    const servers = await this.listMcpServers();
    return servers.find((s) => s.name === name) || null;
  }

  public async deleteMcpServer(name: string): Promise<boolean> {

    } catch {
      return false;
    }
  }

  public async testMcpTool(
    serverName: string,
    toolName: string,
    args: Record<string, any> = {},
    timeoutMs: number = 5000
  ): Promise<{ success: boolean; result?: any; executionTimeMs: number; logs: string; error?: string }> {
    const config = await this.loadMcpConfig();
    const serverEntry = config.mcpServers[serverName];
    if (!serverEntry) {
      return { success: false, executionTimeMs: 0, logs: '', error: `MCP server '${serverName}' not found in registry.` };
    }

    const startTime = Date.now();
    let stdoutData = '';
    let stderrData = '';

    return new Promise((resolve) => {
      let resolved = false;
      const cmd = serverEntry.command;
      const cmdArgs = serverEntry.args.map((a) => path.resolve(this.repoRoot, a));

      const proc = spawn(cmd, cmdArgs, {
        cwd: this.repoRoot,
        env: { ...process.env, ...serverEntry.env },
        stdio: ['pipe', 'pipe', 'pipe'],
      });

      const timer = setTimeout(() => {
        if (!resolved) {
          resolved = true;
          proc.kill('SIGTERM');
          resolve({
            success: false,
            executionTimeMs: Date.now() - startTime,
            logs: stderrData,
            error: `MCP invocation timed out after ${timeoutMs}ms`,
          });
        }
      }, timeoutMs);

      proc.stdout?.on('data', (chunk) => {
        stdoutData += chunk.toString();
        const lines = stdoutData.split('\n');
        for (const line of lines) {
          const trimmed = line.trim();
          if (!trimmed) continue;
          try {
            const msg = JSON.parse(trimmed);
            if (msg.id === 1 && msg.result) {
              // Initialized handshake complete -> send initialized notification & tool call
              proc.stdin?.write(JSON.stringify({ jsonrpc: '2.0', method: 'notifications/initialized' }) + '\n');
              const callReq = {
                jsonrpc: '2.0',
                id: 2,
                method: 'tools/call',
                params: { name: toolName, arguments: args },
              };
              proc.stdin?.write(JSON.stringify(callReq) + '\n');
            } else if (msg.id === 2) {
              if (!resolved) {
                resolved = true;
                clearTimeout(timer);
                proc.kill('SIGTERM');
                resolve({
                  success: !msg.error,
                  result: msg.result,
                  executionTimeMs: Date.now() - startTime,
                  logs: stderrData,
                  error: msg.error?.message,
                });
              }
            }
          } catch {
            // Not a complete JSON-RPC line yet
          }
        }
      });

      proc.stderr?.on('data', (chunk) => {
        stderrData += chunk.toString();
      });

      proc.on('error', (err) => {
        if (!resolved) {
          resolved = true;
          clearTimeout(timer);
          resolve({
            success: false,
            executionTimeMs: Date.now() - startTime,
            logs: stderrData,
            error: `Failed to spawn MCP process: ${err.message}`,
          });
        }
      });

      // Send initial initialize request
      const initReq = {
        jsonrpc: '2.0',
        id: 1,
        method: 'initialize',
        params: {
          protocolVersion: '2024-11-05',
          capabilities: {},
          clientInfo: { name: 'panopticon-tester', version: '1.0.0' },
        },
      };
      proc.stdin?.write(JSON.stringify(initReq) + '\n');
    });
  }

  private generateMcpServerBoilerplate(serverName: string, tools: McpToolDefinition[]): string {
    const handlerStubs = tools
      .map(
        (t) => `  '${t.name}': async (args) => {
    ${t.handlerCode || `return { message: 'Tool ${t.name} executed successfully', args };`}
  }`
      )
      .join(',\n');

    return `/**
 * Auto-generated Model Context Protocol Server: ${serverName}
 */
import readline from 'node:readline';
import fs from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const toolsDir = path.join(__dirname, 'tools');

async function loadTools() {
  const tools = [];
  try {
    const files = await fs.readdir(toolsDir);
    for (const f of files) {
      if (f.endsWith('.json')) {
        const raw = await fs.readFile(path.join(toolsDir, f), 'utf8');
        tools.push(JSON.parse(raw));
      }
    }
  } catch {}
  return tools;
}

const toolHandlers = {
${handlerStubs}
};

const rl = readline.createInterface({ input: process.stdin, output: process.stdout, terminal: false });

function sendResponse(id, result, error = null) {
  const msg = { jsonrpc: '2.0', id };
  if (error) {
    msg.error = error;
  } else {
    msg.result = result;
  }
  process.stdout.write(JSON.stringify(msg) + '\\n');
}

rl.on('line', async (line) => {
  const text = line.trim();
  if (!text) return;

  let req;
  try {
    req = JSON.parse(text);
  } catch {
    sendResponse(null, null, { code: -32700, message: 'Parse error' });
    return;
  }

  const { id, method, params } = req;

  if (method === 'initialize') {
    sendResponse(id, {
      protocolVersion: '2024-11-05',
      capabilities: { tools: {} },
      serverInfo: { name: '${serverName}', version: '1.0.0' },
    });
  } else if (method === 'notifications/initialized') {
    // Client ready
  } else if (method === 'tools/list') {
    const tools = await loadTools();
    sendResponse(id, {
      tools: tools.map((t) => ({
        name: t.name,
        description: t.description,
        inputSchema: t.parameters || { type: 'object', properties: {} },
      })),
    });
  } else if (method === 'tools/call') {
    const { name, arguments: args } = params || {};
    const handler = toolHandlers[name];
    if (!handler) {
      sendResponse(id, null, { code: -32601, message: \`Tool '\${name}' not found\` });
      return;
    }
    try {
      const output = await handler(args || {});
      sendResponse(id, {
        content: [{ type: 'text', text: typeof output === 'string' ? output : JSON.stringify(output) }],
        isError: false,
      });
    } catch (err) {
      sendResponse(id, {
        content: [{ type: 'text', text: err.message }],
        isError: true,
      });
    }
  } else {
    if (id !== undefined) {
      sendResponse(id, null, { code: -32601, message: \`Method '\${method}' not found\` });
    }
  }
});
`;
  }
}
```
